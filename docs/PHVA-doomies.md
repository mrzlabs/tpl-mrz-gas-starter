# PHVA Doomies. tpl-mrz-gas-starter

## PLANEAR
Quiero un molde reusable para arrancar proyectos de Apps Script sin armar todo desde cero cada vez.

## HACER
1. Copio este molde con un click en GitHub
2. Le pongo nombre nuevo al proyecto
3. Conecto con Google Apps Script usando clasp
4. Empiezo a programar en src/main.js

## VERIFICAR
- Tarda menos de 5 min arrancar un proyecto nuevo
- Todos los proyectos se ven igual de ordenados
- Si rompo algo el lint me avisa

## ACTUAR
- Si encuentro algo que repito mucho lo agrego al molde
- Cada mejora aplica a futuros proyectos

## Cierre
Molde vivo. Mejora con cada proyecto nuevo.
