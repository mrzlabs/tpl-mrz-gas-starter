# Seguridad / Security

## Español
Si encuentras una vulnerabilidad, **no abras un issue público**. Usa la pestaña **Security → Report a vulnerability** de este repositorio para enviar un reporte privado. Responderemos lo antes posible.

No incluyas credenciales reales en el reporte. Si un secreto ya se expuso, rótalo primero.

## English
If you find a vulnerability, **do not open a public issue**. Use **Security → Report a vulnerability** in this repository to send a private report. We will reply as soon as possible.

Do not include real credentials in the report. If a secret was already exposed, rotate it first.
