# Contribuir / Contributing

Gracias por el interés. / Thanks for your interest.

## Flujo / Workflow
1. Haz un fork y crea una rama: `git checkout -b feat/mi-cambio`. / Fork and create a branch.
2. Instala dependencias y comprueba el lint: `npm ci && npm run lint`. / Install and lint.
3. Mantén los cambios pequeños y enfocados. / Keep changes small and focused.
4. Actualiza `CHANGELOG.md` si cambia el comportamiento. / Update the changelog if behavior changes.
5. Abre un pull request hacia `main` usando la plantilla. / Open a pull request to `main`.

## Estilo / Style
- Prettier y ESLint definen el formato (`npm run format`). / Prettier and ESLint define formatting.
- Commits con prefijo: `feat`, `fix`, `docs`, `refactor`, `chore`. / Prefixed commit messages.

## Reglas / Rules
- No subas credenciales, `.clasp.json` reales ni archivos `.env`. / Never commit credentials, real `.clasp.json` or `.env` files.
- Sé respetuoso en issues y revisiones. / Be respectful in issues and reviews.
